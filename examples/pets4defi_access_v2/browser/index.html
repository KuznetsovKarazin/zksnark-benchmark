PETs4DeFi browser benchmark

Synthetic demonstration only. This page generates and verifies real Groth16 proofs with snarkjs 0.7.6. It uses public synthetic fixtures; it does not request credentials, connect a wallet, or submit a blockchain transaction.

One session performs 30 cold-worker runs, then one excluded warm-up and 30 warm-worker runs. Every proof must pass strict off-chain verification. Keep this tab visible and avoid other heavy work while it runs.

  • Cold worker: each sample creates a fresh dedicated worker. Worker wall time includes startup, the library, asset loading and hashing, proof generation, verification, and the result message. This does not flush browser, operating-system, or CPU caches.
  • Warm worker: one different worker keeps its JavaScript runtime and loaded asset bytes. Its first verified run is excluded from statistics. Each measured run still calls the complete fullProve API.
  • Single-thread policy: fullProve receives {singleThread: true} as its sixth argument. Nested workers are disabled inside the benchmark worker, activating snarkjs's single-thread verification fallback.
  • Timing: fullProve covers witness calculation and proof generation; off-chain verification is timed separately. Their timers exclude asset downloads. Worker wall time is measured by this page, so it also captures messaging and scheduling overhead.

Results describe this browser session only. No mobile performance is inferred from desktop measurements. The export records user agent, reported hardware concurrency, and device memory if available; no account, location, wallet, or personal inputs are collected.
