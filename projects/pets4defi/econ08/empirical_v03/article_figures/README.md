# Manuscript figures and numerical tables

Run `python build_figures.py` in this directory with the packages in ../requirements.txt. The program reads the archived numeric inputs in the repository and writes four vector PDFs under figures/ plus five LaTeX table bodies under tables/. It checks the two fixed-fee comparisons, cohort frontier, publication slots, balanced historical allocations and the ten-seed summary. The identical script also works in the standalone article or data package with its local figure-data/ directory. Only aggregate numerical inputs are used.
